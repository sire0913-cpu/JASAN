짐싸GO 개인정보처리방침

시행일: 2026년 11월 7일 · 앱 패키지: com.arcraft.jimssa

짐싸GO(이하 “앱”)는 여행 일정과 장소, 메모를 정리하고 일행과 함께 편집할 수 있는 여행 계획 앱입니다. 앱 개발자(이하 “개발자”)는 이용자의 개인정보를 소중히 여기며, 관련 법령을 지키고 있습니다. 이 방침은 앱이 어떤 정보를 어떻게 다루는지 알려 드립니다.

한눈에 보기
  • 회원가입과 로그인이 없고, 광고와 이용자 행태 분석 도구를 사용하지 않습니다.
  • 여행 정보는 기본적으로 이용자의 기기에만 저장됩니다.
  • 이용자가 공유 기능을 직접 켤 때만 해당 여행 정보가 공유 서버에 올라갑니다.
  • 개인정보를 판매하지 않으며, 광고나 마케팅 목적으로 제3자에게 제공하지 않습니다.

1. 수집·이용하는 정보

가. 기기에 저장되는 정보 (개발자 서버로 전송되지 않음)

  • 이용자가 입력한 표시 이름(닉네임), 여행 제목·기간·동행 인원·도시, 일정, 장소, 메모, 평점과 후기, 짐 목록
  • 이용자가 직접 고른 대표 사진(기기 저장소에서 선택한 이미지를 앱 안에 저장)
  • 설정 값, 이용자가 직접 입력한 카카오·네이버 검색용 API 키, 날씨·환율 임시 저장 값

이 정보는 앱 내부 저장소에만 보관되며 앱을 삭제하면 함께 지워집니다.

나. 위치 정보 (이용자가 허용한 경우에만)

지도에 내 위치를 표시하고, 내 주변 장소를 검색하고, 방향(나침반)을 보여 주기 위해 기기의 위치와 방향 센서를 사용합니다. 위치는 해당 기능을 쓰는 동안에만 사용하며 개발자 서버에 저장하지 않습니다. 주변 장소 검색 때에는 좌표가 아래 3항의 지도·검색 서비스로 전달됩니다. 위치 권한을 허용하지 않아도 다른 기능은 이용할 수 있습니다.

다. 공유 기능을 사용할 때 (이용자가 직접 시작한 경우에만)

‘여행 함께 편집’ 또는 ‘모든 여행 공유’를 켜면 공유하는 여행의 제목, 기간, 일정, 장소, 메모와 참여자의 표시 이름, 앱이 임의로 만든 식별 코드가 공유 서버에 저장되어 참여자들에게 동기화됩니다. 이 서버는 Google이 제공하는 클라우드 서비스(Firebase)를 이용합니다. 공유 코드를 아는 사람은 해당 여행에 참여할 수 있으므로 코드는 믿을 수 있는 사람에게만 보내 주세요.

라. 클립보드와 공유

이용자가 ‘붙여넣기’를 누르거나 초대·공유 코드를 열 때 앱이 클립보드나 공유된 내용에서 짐싸GO 공유 코드·백업 데이터를 확인합니다. 이 목적 외에 클립보드 내용을 저장하거나 전송하지 않습니다. 초대 메시지·백업 파일을 다른 앱으로 보내는 것은 이용자가 직접 실행할 때만 일어납니다.

마. 자동으로 수집되는 정보

앱은 광고 식별자, 이용 기록 분석, 비정상 종료 보고 등을 위한 별도 수집 도구를 넣지 않았습니다. 다만 아래 외부 서비스에 접속할 때 해당 서비스 운영자는 이용자의 IP 주소 등 접속 기록을 처리할 수 있습니다.

2. 이용 목적

  • 여행 일정·장소·짐 목록 관리, 지도 표시, 장소 검색, 날씨·환율 안내 등 앱 핵심 기능 제공
  • 이용자가 요청한 여행 공유와 동기화
  • 오류 대응과 이용자 문의 처리

3-1. 정보의 보유와 삭제

  • 기기 안 정보: 앱에서 여행을 삭제하거나 앱을 삭제하면 지워집니다.
  • 공유 서버 정보: 앱의 공유 설정에서 공유를 끝내면 해당 여행이 서버에서 정리됩니다. 공유를 끝낼 때 상대방 기기의 사본까지 지울지 선택할 수 있습니다.
  • 서버에 남은 정보의 삭제는 아래 문의처로 요청해 주세요. 확인 후 지체 없이 처리합니다.
  • 백업 파일로 직접 내보낸 정보는 이용자가 관리하는 정보이므로 앱이 삭제할 수 없습니다.

4. 이용자의 권리

이용자는 언제든지 자신의 정보를 앱에서 조회·수정·삭제할 수 있고, 위치 등 권한은 기기 설정에서 철회할 수 있습니다. 서버에 저장된 정보의 열람·정정·삭제·처리정지는 아래 문의처로 요청할 수 있습니다.

5. 안전성 확보 조치

공유 서버와의 통신에는 암호화(HTTPS)를 사용하며, 서버 접근은 필요한 범위로 제한합니다. 이용자가 직접 입력한 API 키는 해당 기기에만 저장됩니다. 다만 인터넷을 통한 전송과 저장은 완전한 안전을 보장할 수 없습니다.

6. 아동의 개인정보

앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다. 아동의 정보가 공유 서버에 올라간 사실을 알게 되면 지체 없이 삭제합니다.

7. 방침의 변경

이 방침의 내용이 바뀌면 시행일과 함께 이 페이지에 공지합니다. 수집하는 정보나 이용 목적이 크게 달라질 때는 앱 안에서도 알립니다.
